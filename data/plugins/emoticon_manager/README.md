# 🧰 情绪表情包（emoticon_manager）—— AstrBot 简单表情包插件

一个简单的表情包插件，支持随机发送、情感匹配与 WebUI 管理编辑表情包。

基于 AstrBot 最新官方插件规范（Star 插件体系 + Plugin Pages WebUI）开发，
适配 AstrBot WebUI 与 NapCat / OneBot（aiocqhttp）适配器，兼容 QQ 机器人。

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 自动模式（核心） | 机器人完成回复后，按概率随机补发一张表情包 |
| 情感匹配（可选） | 开启后只总结机器人本次输出的内容（不附加对话上下文）并判断情感标签，挑选最匹配的表情包 |
| `#表情包` / `#随机表情` | 手动发送表情包（不受概率限制，始终发送） |
| `#表情列表 [页码]` | 分页输出所有表情包文件名 |
| `#表情删除 文件名` | 删除指定表情包文件 |
| `#表情设置` | 查看当前表情配置（自动开关 / 策略 / 数量 / 概率 / 间隔） |
| WebUI 管理页面 | 网页上传（jpg/jpeg/png/gif 与 zip 自动提取，最大 8MB）、在线预览、一键删除、为表情打情感标签并筛选 |

表情包统一存放在插件目录 `static/emoticons/` 下，纯本地文件管理，
表情标签存放在插件目录 `data/tags.json`（纯本地 JSON 元数据文件），
不使用第三方数据库，不依赖任何额外 Python 包。

## 🎯 自动模式与表情发送配置（插件设置）

**自动模式**是插件的核心功能：机器人每完成一次回复（消息发送到平台后），
插件会按 `emoticon_probability` 概率判定是否触发，触发后按
`selection_strategy` 策略挑选表情包补发一条图片消息。

选择策略为 `tag`（情感匹配）时，插件只读取机器人**本次输出的回复文本**
（`after_message_sent` 时 `event.get_result()` 的内容），调用当前会话的
对话模型判断这段输出的情感标签，再挑选带该标签的表情包发送；**不会把
整段对话上下文塞进提示词**。候选情感标签**自动从表情库收集**：所有表情
在管理页面打过的标签会去重后作为模型的选项，无需手动维护标签列表；
表情库还没有任何标签时，情感匹配直接跳过。若未开启情感匹配、模型不可用
或没有对应标签的表情，则按 `emotion_fallback_random` 配置回退随机发送
或不发送。

在 AstrBot WebUI → 插件 → 情绪表情包 → **设置** 中可配置以下项，
全部即时生效，无需重启：

| 配置项 | 取值范围 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `auto_send_enabled` | `true` / `false` | `true` | 自动模式总开关；关闭后只保留手动指令 |
| `selection_strategy` | `random` / `round_robin` / `tag` | `random` | 表情选择策略：`random` 随机发送且避免连续两次重复；`round_robin` 按文件名顺序轮流发送，同一轮内不重复；`tag` 情感匹配（需开启下方情感匹配总开关） |
| `emotion_match_enabled` | `true` / `false` | `false` | 情感匹配总开关；开启后 `tag` 策略生效，调用当前对话模型分析机器人输出判断情感标签（需要 AstrBot 已配置对话模型）；候选标签自动从表情库标签中收集，无需手动配置 |
| `emotion_fallback_random` | `true` / `false` | `true` | 情感匹配失败（模型不可用 / 未找到对应标签表情）时是否回退随机发送；`false` 表示匹配失败则不发送 |
| `max_emoticons_per_reply` | 1 - 10 | 1 | 每次回复最多使用表情数量，设置大于 1 时一次回复会发送多张表情（自动与手动均生效） |
| `emoticon_probability` | 0 - 100 | 100 | 自动模式触发概率（百分比），100 表示每次回复都出表情，50 表示平均两次触发一次，0 表示不触发（仅影响自动模式） |
| `min_interval_seconds` | 0 - 3600 | 10 | 同一会话两次自动表情的最小间隔秒数，防止机器人一次对话连续刷出多张表情 |

自动模式通过 AstrBot 官方 `@filter.after_message_sent()` 事件钩子实现：
钩子在机器人消息发送到平台后触发，自带防递归保护（自动表情不会再次触发
自己），并按会话间隔冷却。可在聊天中发送 `#表情设置` 随时查看当前生效的配置。

## ⚙️ 环境要求

- AstrBot **>= 4.24.2**（需要 Plugin Pages 能力，即插件自定义 WebUI 页面）
- Python 3.10+（AstrBot v4 运行环境自带）
- 适配器：`aiocqhttp`（NapCat / OneBot v11 / QQ）

> 说明：本插件遵循 AstrBot v3.4+ 官方规范。旧版规范中的
> `astrbot.api.plugin.Plugin`、`@command` 装饰器、`__init__.py` 入口
> 属于 v2 时代 API，在当前 AstrBot 中已无法加载，请勿混用。

## 📦 安装部署

### 方式一：目录安装（推荐）

1. 将 `emoticon_manager` 整个文件夹复制到 AstrBot 的插件目录：

   ```
   <AstrBot 根目录>/data/plugins/emoticon_manager/
   ```

2. 重启 AstrBot，或进入 WebUI → 插件管理 → 右上角 `...` → 重载插件。

3. 确认插件卡片「情绪表情包」状态为启用。首次启动会自动创建
   `static/emoticons/` 存储目录。

### 方式二：ZIP 安装

将 `emoticon_manager` 文件夹压缩为 zip（压缩包内直接包含 `main.py`、
`metadata.yaml`，不要多套一层目录），然后在 WebUI → 插件管理 →
安装插件 → 上传 zip 安装。

## 🤖 聊天指令

> 指令前缀跟随 AstrBot 全局配置（默认 `/`；在 WebUI 设置中把命令前缀
> 改为 `#` 即可使用 `#表情包` 这类写法），下方以 `#` 为例。

### `#表情包` / `#随机表情`

随机发送一张表情包图片。表情库为空时回复：
`暂无表情包，请前往插件管理页面上传！`

### `#表情列表`

分页列出全部表情包文件名（每页 20 条）：

```
📚 共 35 个表情包：
1. 猫猫.jpg
2. 哈哈哈.gif
...
—— 第 1/2 页，发送 #表情列表 2 查看下一页 ——
```

### `#表情删除 文件名`

删除指定表情包（需带扩展名，支持忽略大小写匹配）：

```
#表情删除 猫猫.jpg
✅ 已删除表情包：猫猫.jpg
```

文件不存在时回复 `未找到名为「xxx」的表情包文件...`。

### `#表情设置`

查看当前表情选择策略（选择策略 / 情感匹配开关 / 标签列表 /
每次回复最多表情数量 / 出现概率）。
修改请前往 AstrBot WebUI 插件设置页。

## 🖥️ WebUI 管理页面

1. 进入 AstrBot WebUI → 左侧「插件」→ 找到「情绪表情包」。
2. 点击插件详情页中的 **情绪表情包管理** 页面。
3. 页面功能：
   - **上传**：点击上传区域或直接拖拽图片（支持多选），
     自动校验后缀、大小（≤ 8MB）与图片真实格式；也可上传 **zip 压缩包**，
     插件会自动解压并提取其中所有符合规范（jpg/jpeg/png/gif、≤ 8MB）的图片，
     非法文件与目录结构自动忽略，同名文件自动追加序号不覆盖。
   - **预览**：网格在线预览所有表情包（超过 1MB 的图片提供下载按钮）。
   - **打标签**：每张表情卡片有「🏷️ 标签」按钮，可输入或点选已有标签
     为表情打情感标签（如「开心」「难过」），保存后写入 `data/tags.json`；
     已打的标签可直接点 × 移除。
   - **标签筛选**：页面顶部标签栏列出全部标签及数量，点击标签只显示
     带该标签的表情，再点「全部」恢复。
   - **删除**：点击「删除」→ 再点「确认删除？」完成二次确认。
   - **刷新**：上传/删除后列表自动刷新，也可手动刷新。

> 提示：情感匹配（`tag` 策略）依赖表情标签。请先在管理页面为表情打好
> 情感标签，再在插件设置中开启「情感匹配 总开关」并选择 `tag` 策略。

## 🌐 Web 接口说明

接口通过 AstrBot Plugin Pages 规范注册（路由自动带插件名前缀），
页面内相对接口（桥接层调用）与对外完整路径对应如下：

| 页面内相对路径 | 完整路径 | 方法 | 说明 |
| --- | --- | --- | --- |
| `list` | `/api/v1/plugins/extensions/emoticon_manager/list` | GET | 获取全部表情包（含 base64 预览） |
| `upload` | `/api/v1/plugins/extensions/emoticon_manager/upload` | POST | 上传图片或 zip 压缩包（表单字段 `file`） |
| `delete` | `/api/v1/plugins/extensions/emoticon_manager/delete` | DELETE/POST | 删除表情包（`filename` 参数/字段） |
| `file` | `/api/v1/plugins/extensions/emoticon_manager/file` | GET | 获取表情文件（下载/预览） |
| `tag` | `/api/v1/plugins/extensions/emoticon_manager/tag` | POST | 设置表情标签（支持 `set` / `add` / `remove` 三种动作） |
| `tags` | `/api/v1/plugins/extensions/emoticon_manager/tags` | GET | 获取全部标签及统计（供页面筛选栏） |

完整路径为 Dashboard 对外路径；页面通过
`bridge.apiGet("list")` / `bridge.upload("upload", file)` /
`bridge.apiPost("delete", {filename})` 等桥接方法调用。
出于安全考虑，删除接口同时兼容 DELETE（query 传 `filename`）与
POST（JSON 体传 `filename`）两种调用方式。

## 🛡️ 安全设计

- **路径穿越防护**：所有文件名先清洗为纯 basename，再对最终路径
  `resolve()` 校验父目录，双重拦截 `../`、绝对路径与符号链接越界。
- **非法类型过滤**：仅允许 `.jpg/.jpeg/.png/.gif`，上传后校验文件头
  （魔数），拒绝改名伪装的文件；扫描目录时过滤其他一切文件。
- **标签安全**：标签写入前逐字清洗（去控制字符/路径分隔符/引号，
  限长 20 字、每图最多 20 个标签）；标签数据按表情文件名索引，
  文件名仍走路径穿越防护校验，标签文件本身只存放在 `data/` 目录。
- **ZIP 安全解压**：zip 压缩包上传时逐条目做路径穿越防护（zip-slip），
  仅提取符合规范的图片；单文件 ≤ 8MB、解压总量 ≤ 64MB、条目数 ≤ 500，
  防解压炸弹；加密/损坏条目自动跳过。
- **大小限制**：上传前后双重校验，单文件最大 8MB。
- **Windows 安全**：拦截保留设备名（CON/PRN/COM1 等）与隐藏文件。
- **防覆盖**：同名文件自动追加 `_1/_2` 序号，不覆盖已有表情。
- **并发安全**：文件操作加互斥锁，临时文件先写后校验、失败自动清理。

## ❓ 常见问题

**Q：为什么指令前缀是 `/` 而不是 `#`？**
A：指令前缀由 AstrBot 全局配置决定，默认是 `/`。在 WebUI 设置中将
命令前缀改为 `#` 后即可使用 `#表情包`。

**Q：发送图片失败/无法显示？**
A：本地图片发送要求协议端（NapCat）与 AstrBot 运行在同一台机器上；
跨机部署时可把表情目录放到共享路径或改用图床方案。另外请关闭
「分段回复」或开启「流式传输兼容模式」相关选项（见 AstrBot 设置）。

**Q：修改页面代码后不生效？**
A：刷新页面即可；新增/删除 `pages/` 目录或修改 `main.py` 后需
在插件管理中重载插件。

**Q：表情包会随插件更新被覆盖吗？**
A：表情文件保存在插件目录 `static/emoticons/` 下，更新插件前请先
备份该目录（官方建议长期数据放 `data/`，如介意可自行调整路径常量
`EMOTICONS_DIR`）。

**Q：为什么选择 tag 策略后还是随机发表情？**
A：请检查三点：① 插件设置里「情感匹配 总开关」是否开启；
② 表情包是否已在管理页面打好对应标签（未打标签的表情不参与匹配）；
③ AstrBot 是否配置了可用的对话模型。以上任一不满足时，插件会按
「匹配失败 回退随机」配置回退为随机发送。

**Q：情感分析会把整段聊天记录发给模型吗？**
A：不会。插件只把机器人**本次输出的回复文本**发给模型做情感判断，
不会携带用户消息或历史对话上下文。
