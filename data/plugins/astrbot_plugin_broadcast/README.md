QQ 广播助手插件

> 作者：艾珀莉亚（FionaFaust）

QQ 平台广播助手插件，基于 AstrBot 开发，适用于 NapCat（OneBot v11 / aiocqhttp 适配器）与 **QQ 官方机器人**（qq_official / qq_official_webhook），支持群聊与私聊

功能一览

| 定时群发 | 在配置的时间（24 时制）自动向白名单群聊发送预设内容，可开关
| 启动通知 | 机器人启动且 aiocqhttp 适配器连接成功后，向所有群聊发送预设通知，可开关
| 指令广播 | /广播 {群聊id或群名} {内容} 向指定群聊发消息；/广播 {个人id} {内容} 向个人发消息（**需要 AstrBot 管理员**） |
| 群聊列表 | /群聊列表 查看本地缓存（KV）里记录过的群聊，方便填写白名单 | 始终可用 |

安装方法

1. 将 astrbot_plugin_broadcast 文件夹放入 AstrBot 的data/plugins/目录；
2. 在 AstrBot WebUI 的 插件管理 中启用本插件；
3. 点击插件配置，按需填写下列配置项并保存。

配置说明（WebUI 可视化配置）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| enable_scheduled | bool | false | 是否开启定时群发功能 |
| scheduled_time | string | 08:00 | 定时发送时间（24 时制，格式 HH:MM，如 08:00、21:30） |
| scheduled_content | text | 早安问候语 | 定时群发发送的文本内容 |
| scheduled_group_ids | list | 空 | 定时群发目标白名单群聊 ID：OneBot 填群号（数字），QQ 官方机器人填 group_openid（用 /群聊列表 查看） |
| enable_startup | bool | false | 是否开启启动通知功能 |
| startup_content | text | 机器人已启动 | 启动通知内容（OneBot 取群列表，官方平台取本地缓存的群聊） |

> 提示 scheduled_group_ids **仅用于定时群发**；`/广播` 指令不受白名单限制，可直接向指定群聊发送（目标需是机器人所在的群）。

> 权限：`/广播` 仅 **AstrBot 管理员**可用——在 WebUI 的「管理员ID列表」（`admins_id`）中加入使用者的 QQ 号（OneBot）或 openid（官方平台）即可；平台自带的群管理员角色不会自动放行。非管理员发送时会收到"权限不足"提示（含其 ID，方便直接复制进名单）。

指令用法

广播到群聊（群号或群名皆可，群名可含空格）
/广播 123456789 大家好，今晚 8 点有活动！
/广播 OneBot测试群 test

广播到个人
/广播 987654321 你好，你的快递已到！

>说明：
指令会自动识别目标是群聊还是个人（官方平台只支持向群聊发消息，个人请用 OneBot）；
群聊目标直接发送（白名单只限制定时群发），个人目标不限制；
群聊目标可用 QQ 号/群号、group_openid，或用**群名**（取自本地缓存，支持忽略大小写；同名多群时会提示改用群 ID）；个人目标仅 OneBot 平台，ID 为 QQ 号（数字）。

使用场景示例

定时群发：每天 08:00 向群聊发送早报、每日签到提醒；
启动通知：机器人重启后自动告知所有群聊"已上线"；
指令广播：管理员手动向指定群或个人推送公告、通知。

注意事项

QQ 官方机器人没有群列表接口，插件会在**群里有消息时**把群记进本地缓存（`数据目录/plugin_data/astrbot_plugin_broadcast/group_cache.json`），定时群发/启动通知/群聊列表都基于它；新拉的群先发一句话即可入库；
定时任务以 20 秒为周期检查时间，实际发送时间可能有最多 20 秒的延迟；
主动向个人发送消息受 QQ 平台限制，若对方未与机器人有过会话，可能无法送达；
修改配置后建议在 WebUI 中「重载插件」使新配置生效。

## 群聊缓存（KV）

- 结构：`{平台实例ID: {群ID: {"name": 群名, "seen": 首次记录时间}}}`，各平台各自独立；
- 来源：群消息事件（含群名解析，官方平台查群信息接口）、OneBot 的群列表接口；
- 用途：官方平台没有群列表接口，定时群发与启动通知依赖它；`/群聊列表` 可直接查看。
